# TinkerTill public pages

The public web pages for the TinkerTill app, served with GitHub Pages at
**https://tinkertill.com/** (custom domain; DNS at Namecheap, set in Settings → Pages). Old
`https://sumr415.github.io/tinkertill-site/...` links forward to it.

| Page | Link | Used for |
|---|---|---|
| Delete your account or data | https://tinkertill.com/delete-account.html | Google Play: Delete account URL |
| Delete only some data | https://tinkertill.com/delete-account.html#delete-data | Google Play: Delete data URL |
| Privacy policy | https://tinkertill.com/privacy-policy.html | Google Play and App Store privacy policy link |
| Email confirmed | https://tinkertill.com/confirmed.html | Supabase Site URL; the sign-up email link lands here |
| Choose a new password | https://tinkertill.com/reset-password.html | Supabase Redirect URL; the password-reset email link lands here |
| Terms of use | https://tinkertill.com/terms-of-use.html | App Store and Google Play terms link; linked from every page |

The app's code is in a separate, private repository. These pages are edited there first (in its `site/`
folder) and copied here.
